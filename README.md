Live Demo: https://scamshield-ai.streamlit.app/

ScamShield AI is an AI-powered decision intelligence platform that helps users evaluate scams, internships, certifications, job offers, and career plans.
ScamShield AI is an AI-powered platform that helps users evaluate:

- Scam messages
- Job opportunities
- Internships
- Certifications
- Career plans

Built with:
- Python
- Streamlit
- OpenRouter
- AI-powered opportunity analysis

## Features

- Scam Detection
- Opportunity Analyzer
- Career Validator
- Certification Checker
- Reality Check AI

## Run Locally

pip install -r requirements.txt

streamlit run app.py
